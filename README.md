A one-image front page summing up 21 November 2026 world news: Iran striking US bases in Bahrain as the lead, Mexico capturing "El Chapo Isidro", a missile hitting Kryvyi Rih, and the COP31 talks running into overtime, with a strip of shorter items along the bottom. `build_image.py` documents how the page is drawn; `entry.png` is the submitted image and `main.py` copies it to the output directory.

## Run it

```sh
python3 main.py
```

The image is 1024x1024 and under 1 MiB.
